# lemonPPT 图表与内容组件设计规范

> 基于 Dashi PPT theme01 的视觉研究，抽象出可复用的组件模式。
> 本规范只借鉴「信息架构与叙事方式」，不涉及 Dashi 的具体代码、配色、文案与布局结构。

---

## 1. 设计原则

### 1.1 一图一结论

每张数据页必须有且只有一句核心结论。图表不是装饰品，而是论证工具。

- ❌ 不好：`2024 年各季度融资额`
- ✅ 更好：`Q2-Q3 是全年融资高峰，占全年 63%`

### 1.2 数字需要上下文

孤立的大数字没有说服力，必须跟一句人话解释。

- ❌ 不好：`970 亿美元`
- ✅ 更好：`970 亿美元 · 创历史新高，占全美风险投资近三分之一`

### 1.3 图表 + 解读面板

主视觉只承担 60% 的信息量，剩余 40% 交给文字解读。典型结构：

```
┌─────────────────────────────────────┐
│  标题                                │
│  副标题 / 一句话结论                  │
├──────────────────┬──────────────────┤
│                  │                  │
│   图表/主视觉     │   洞察面板        │
│   (60%)          │   (40%)          │
│                  │                  │
├──────────────────┴──────────────────┤
│  脚注 / 数据来源 / 深层解释           │
└─────────────────────────────────────┘
```

### 1.4 颜色即语义

每个分类一旦在图表中被赋予颜色，在列表、标签、卡片中必须保持一致。

### 1.5 信息分层

每页内容按以下层级组织：

1. 标题（最大字号，结论性）
2. 副标题 / 一句话洞察
3. 主视觉（图表、数字、图片）
4. 关键标签 / 高亮结论
5. 详细解释 / 数据列表
6. 脚注 / 数据来源

## 2. 组件规范

### 2.01 CoverEditorial · 编辑式封面

**使用场景**：报告、年报、白皮书等正式文档的封面。

**结构**：

```
┌─────────────────────────────────────┐
│                                     │
│  [年度报告 · VOL.07]                │
│                                     │
│  新消费趋势                         │
│  年度报告                            │
│  ANNUAL CONSUMER TRENDS REPORT      │
│                                     │
│  横纵双维，解码一年的消费迁徙与品牌机会。│
│                                     │
│  [消费迁徙] [品牌机会] [增长信号]   │
│                                     │
│                  ┌────────────────┐ │
│                  │ REPORT 2026    │ │
│                  │ EDITION Vol.07 │ │
│                  │ RELEASE 2026·06│ │
│                  │ ISSUED BY      │ │
│                  │ 灯塔研究院      │ │
│                  └────────────────┘ │
│                                     │
│  脚注                                │
└─────────────────────────────────────┘
```

**Props**：

| 字段 | 类型 | 说明 |
|---|---|---|
| `title` | string | 主标题 |
| `subtitle` | string | 英文/中文副标题 |
| `kicker` | string | 顶部标签，如“年度报告 · VOL.07” |
| `lead` | string | 导语/一句话说明 |
| `chips` | string[] | 关键词标签 |
| `panel` | { title: string; index: string; meta: { label: string; value: string }[] } | 右侧信息面板 |
| `footnote` | string | 脚注 |

**视觉要点**：

- 左侧大标题区 + 右侧玻璃/卡片信息面板。
- 标题使用最大字号，可分上下两行排布。
- 关键词标签位于导语下方，增强内容预期。
- 右侧面板包含期号、发布时间、发布机构等元信息。
- 背景可用柔光 bokeh 或渐变，提升质感。

### 2.02 CoverMinimal · 极简封面

**使用场景**：品牌白皮书、理念发布、轻量报告封面。

**结构**：

```
┌─────────────────────────────────────┐
│                                     │
│            ● 玻璃光球               │
│                                     │
│      GLOBAL BRAND GROWTH            │
│                                     │
│         全球品牌                    │

│                                     │
│      从规模扩张到价值深耕            │
│                                     │
│   [增长飞轮] [价值复利] [长期主义]  │
│                                     │
│         2026 年度版 · 灯塔研究院     │
│                                     │
│  脚注                                │
└─────────────────────────────────────┘
```

**Props**：

| 字段 | 类型 | 说明 |
|---|---|---|
| `kicker` | string | 顶部英文/中文小字 |
| `title` | string | 主标题 |
| `subtitle` | string | 副标题 |
| `pills` | string[] | 底部药丸关键词 |
| `meta` | string | 底部元信息 |
| `showOrb` | boolean | 是否显示顶部玻璃光球 |
| `footnote` | string | 脚注 |

**视觉要点**：

- 整体居中对齐，视觉焦点在标题。
- 顶部可加一个半透明玻璃光球作为装饰锚点。
- 药丸标签比矩形标签更柔和。
- 背景使用大面积浅色 + 散落柔光光斑。

### 2.03 ChapterTransition · 章节过渡页

**使用场景**：演讲中的章节切换页，提示观众进入新主题。

**结构**：

```
┌─────────────────────────────────────┐
│                                     │
│  [章节]  PART 03                    │
│                                     │
│        03 横向透视                  │
│  HORIZONTAL PERSPECTIVE             │
│                                     │
│  在同一时间截面上，横向对比公司、赛道、 │
│  轮次与地区——谁更大、谁更密集、        │
│  资源集中在哪里。                      │
│                                     │
│  [行业赛道] [轮次结构] [头部玩家]      │
│  [地区分布] [资本四象限]              │
│                                     │
│  脚注                                │
└─────────────────────────────────────┘
```

**Props**：

| 字段 | 类型 | 说明 |
|---|---|---|
| `part` | string | 章节编号，如 "03" |
| `title` | string | 章节标题 |
| `subtitle` | string | 英文/中文副标题 |
| `description` | string | 章节说明文字 |
| `topics` | string[] | 本章包含的子主题标签 |
| `watermark` | string | 背景水印文字（可选） |
| `footnote` | string | 脚注 |

**视觉要点**：

- 章节号使用超大字号，与标题形成层次。
- 背景可加半透明巨型数字/文字水印，增强视觉冲击力。
- 子主题标签横向排列，预告本章内容。
- 整体留白充足，不要塞太多信息。

### 2.04 BigNumber · 大数字页

**使用场景**：展示一个核心指标及其上下文，如融资总额、用户数、增长率。

**结构**：

```
┌─────────────────────────────────────┐
│  标题                                │
│  副标题 / 一句话洞察                  │
│                                     │
│        970 亿美元                    │
│   创历史新高，占全美风险投资近 1/3   │
│                                     │
│  [97 笔]  [≈10 亿]  [43.3%]        │
│                                     │
│  脚注                                │
└─────────────────────────────────────┘
```

**Props**：

| 字段 | 类型 | 说明 |
|---|---|---|
| `title` | string | 页面标题 |
| `subtitle` | string | 一句话洞察 |
| `value` | string / number | 主数值 |
| `unit` | string | 单位，如“亿美元”、“%” |
| `context` | string | 主数值下方的人话解释 |
| `metrics` | MetricCard[] | 底部辅助指标卡 |
| `footnote` | string | 底部脚注 |

**MetricCard 结构**：

```ts
interface MetricCard {
  value: string;
  label: string;
  accent?: boolean; // 是否使用主题色强调
}
```

**视觉要点**：

- 主数值字号远大于其他元素，形成视觉锚点。
- 单位使用主题色，与主数值形成对比。
- 指标卡横向等分或根据数量自动排列（2~4 个）。
- 整体居中对齐，适合演讲时远距离阅读。

### 2.05 ChartWithInsight · 图表 + 洞察面板

**使用场景**：趋势、对比、时间序列等需要解释的数据图表。

**结构**：

```
┌─────────────────────────────────────┐
│  标题 · 纵向趋势 · 逐季度融资走势     │
│  副标题 · VERTICAL TREND            │
├──────────────────┬──────────────────┤
│                  │   970 亿美元      │
│    柱状图         │   FULL-YEAR TOTAL│
│                  │   97 DEALS       │
│   Q1 Q2 Q3 Q4    │   事件笔数  97 笔 │
│                  │   平均单笔  ≈10 亿│
│                  │   ┌─────────────┐ │
│                  │   │ Q2-Q3 为高峰 │ │
│                  │   └─────────────┘ │
├──────────────────┴──────────────────┤
│  脚注 · 数据来源与趋势解释            │
└─────────────────────────────────────┘
```

**Props**：

| 字段 | 类型 | 说明 |
|---|---|---|
| `title` | string | 页面标题 |
| `subtitle` | string | 英文/中文副标题 |
| `chart` | ChartConfig | 图表配置（类型、数据、颜色） |
| `insight` | InsightPanel | 右侧洞察面板 |
| `footnote` | string | 底部脚注 |

**InsightPanel 结构**：

```ts
interface InsightPanel {
  headline?: string;      // 大标题，如年度总额
  subheadline?: string;   // 小字说明，如 FULL-YEAR TOTAL
  items: { label: string; value: string }[];
  badge?: { text: string; tone?: 'accent' | 'success' | 'warning' }; // 高亮结论标签
}
```

**视觉要点**：

- 主图表区占 55%~65%，洞察面板占 35%~45%。
- 洞察面板使用卡片容器，与主图表区形成材质对比。
- 高亮标签使用主题色背景或边框，吸引注意力。
- 图表坐标轴、标签使用 muted 颜色，不抢主体。

**支持的图表类型（MVP）**：

- 柱状图（Bar）
- 折线图（Line）
- 面积图（Area）

### 2.06 DonutBreakdown · 环形图 + 分类解读

**使用场景**：占比分布、结构拆解、市场份额。

**结构**：

```
┌─────────────────────────────────────┐
│  标题 · 赛道分布 · 融资额占比         │
│  副标题 · 97 笔大额融资的赛道归类     │
├──────────────────┬──────────────────┤
│                  │  ■ 通用大模型     │
│    环形图         │    43.3%  420 亿  │
│                  │  ■ 垂直应用       │
│   970 亿美元      │    25.3%  245 亿  │
│    全年合计       │  ■ AI 基础设施    │
│                  │    16.3%  198 亿  │
│                  │  ■ AI 芯片        │
│                  │    10.0%   97 亿  │
│                  │  ■ 其他           │
│                  │     5.1%   50 亿  │
├──────────────────┴──────────────────┤
│  脚注 · 分布背后的趋势解读            │
└─────────────────────────────────────┘
```

**Props**：

| 字段 | 类型 | 说明 |
|---|---|---|
| `title` | string | 页面标题 |
| `subtitle` | string | 副标题 |
| `total` | { value: string; label: string } | 环形图中心合计 |
| `segments` | Segment[] | 分类数据 |
| `footnote` | string | 底部解读 |

**Segment 结构**：

```ts
interface Segment {
  label: string;
  labelEn?: string;
  value: string;
  percent: string;
  color: string;
}
```

**视觉要点**：

- 环形图中心必须显示合计值，一眼感知整体规模。
- 分类列表按占比降序排列。
- 每个分类前有色块/圆点，与图表颜色一一对应。
- 分类标签下可加一行英文小字，提升专业感（可选）。

### 2.07 FunnelInsight · 漏斗 + 关键结论

**使用场景**：展示层级筛选、集中度、漏斗转化。

**结构**：

```
┌─────────────────────────────────────┐
│  标题 · 资金集中度 · 赢家通吃         │
│  副标题 · 资金如何向头部集中          │
├──────────────────┬──────────────────┤
│                  │                  │
│   漏斗图          │   24%            │
│                  │   头部 10 家     │
│  970 亿           │   = 全市场近 1/4 │
│  232 亿           │                  │
│  181 亿           │   少数独角兽反复 │
│   66 亿           │   获得巨额追加   │
│                  │   投资，头部格局 │
│                  │   已然确立。     │
├──────────────────┴──────────────────┤
│  脚注                                │
└─────────────────────────────────────┘
```

**Props**：

| 字段 | 类型 | 说明 |
|---|---|---|
| `title` | string | 页面标题 |
| `subtitle` | string | 副标题 |
| `funnel` | FunnelStep[] | 漏斗各层数据 |
| `insight` | { value: string; label: string; description: string } | 右侧结论 |
| `footnote` | string | 脚注 |

**FunnelStep 结构**：

```ts
interface FunnelStep {
  value: string;
  label: string;
  sublabel?: string;
}
```

**视觉要点**：

- 漏斗层级递减，最上层最宽，最下层最窄。
- 每层显示数值 + 标签 + 可选小字说明。
- 右侧结论区用大数字做锚点，下方跟 2~3 行解释。
- 适合展示“从整体到头部”的收敛过程。

### 2.08 DataTable · 排行表格

**使用场景**：Top 10 排行、榜单、明细数据展示。

**结构**：

```
┌─────────────────────────────────────┐
│  头部玩家 · 单笔融资 Top 10          │
│  单笔融资额最大的 10 家公司          │
├─────────────────────────────────────┤
│  排名·公司    主要赛道    融资额/亿美元 │
├─────────────────────────────────────┤
│  1 OpenAI     通用大模型      66    │
│  2 Anthropic  通用大模型      65    │
│  3 xAI        通用大模型      50    │
│  ...                                │
├─────────────────────────────────────┤
│  脚注                                │
└─────────────────────────────────────┘
```

**Props**：

| 字段 | 类型 | 说明 |
|---|---|---|
| `title` | string | 页面标题 |
| `subtitle` | string | 副标题 |
| `columns` | { key: string; label: string; align?: 'left' \| 'right' \| 'center' }[] | 表头定义 |
| `rows` | Record<string, string>[] | 表格数据 |
| `highlightRows` | number[] | 需要高亮强调的行索引 |
| `footnote` | string | 脚注 |

**视觉要点**：

- 表头使用主题色渐变背景，与行数据形成区分。
- 行与行之间用 zebra striping 或细线分隔，提升可读性。
- 重点行（如 Top 3）可用主题色文字或背景高亮。
- 数字列右对齐，文本列左对齐。
- 表格宽度占满内容区，不留大面积空白。

### 2.09 SpotlightGrid · 主题聚焦网格

**使用场景**：并列展示 2~4 个主题/案例/分论点。

**结构**：

```
┌─────────────────────────────────────┐
│  钱，最终砸向了这三件事              │
├──────────┬──────────┬──────────────┤
│ [标签 1] │ [标签 2] │ [标签 3]     │
│          │          │              │
│  图片    │  图片    │  图片        │
│          │          │              │
│ 标题 1   │ 标题 2   │ 标题 3       │
│ 描述 1   │ 描述 2   │ 描述 3       │
└──────────┴──────────┴──────────────┘
```

**Props**：

| 字段 | 类型 | 说明 |
|---|---|---|
| `title` | string | 页面主标题 |
| `subtitle` | string | 副标题 |
| `columns` | SpotlightColumn[] | 2~4 列内容 |

**SpotlightColumn 结构**：

```ts
interface SpotlightColumn {
  tag?: string;        // 顶部标签/分类
  title: string;       // 列标题
  description: string; // 列描述
  media?: MediaSource; // 图片或图标
}
```

**视觉要点**：

- 列数建议 2~4，3 列最常见。
- 每列顶部有标签，底部有标题+描述，中间是视觉区。
- 列与列之间用细线或间距分隔，保持整齐。
- 适合“一个中心论点 + 多个支撑论据”的叙事。

**Props**：

interface CaseMilestone {

- 时间线/融资列表用色块或标签标注不同阶段。
- 重点融资可用主题色高亮。
- 底部金句使用引用样式，署名 + 职位。
- 右侧图片区可放公司 Logo、产品截图或代表人物。

### 2.11 Timeline · 里程碑时间轴

**使用场景**：展示融资节奏、产品迭代、项目里程碑、事件时间线。

**结构**：

```
┌─────────────────────────────────────┐

│  副标题 · 一年三轮 · 估值 16 倍跃迁      │
│                                     │
│  ──●────────●────────●────────●──── │
│   2024·05  2024·08  2024·11  2025·H2│
│   ┌──┐    ┌──┐    ┌──┐    ┌──┐     │
│   │280│   │190│   │180│   │IPO│    │
│   │Series G│ │Series F+│ │Series H│ │上市│
│   └──┘    └──┘    └──┘    └──┘     │
│                                     │
│  脚注                                │
└─────────────────────────────────────┘
```

**Props**：

| 字段 | 类型 | 说明 |
|---|---|---|
| `title` | string | 页面标题 |
| `subtitle` | string | 副标题 |
| `events` | TimelineEvent[] | 时间轴事件 |
| `footnote` | string | 脚注 |

**TimelineEvent 结构**：

```ts
interface TimelineEvent {
  date: string;        // 如 "2024 · 05"
  title: string;       // 事件标题
  value?: string;      // 关键数字，如 "280 亿"
  subtitle?: string;   // 补充说明，如 "Series G"
  description?: string; // 详细解释

  accent?: boolean;    // 是否重点强调

```

**视觉要点**：

- 时间轴为横向主线，节点用圆点标记。
- 事件卡片交替分布在时间轴上下方，避免拥挤。
- 重点事件可用主题色卡片或放大字号强调。
- 每个事件卡片包含：日期、数字、标题、补充说明。

### 2.15 DiptychContrast · 双联对比

**使用场景**：展示矛盾、转折、前后对比、两种立场/状态。

**结构**：

```
┌─────────────────────────────────────┐
│  [叙事估值]          [真实兑现]      │
│                                     │
│   左半区背景图        右半区背景图    │
│                                     │
│      ┌─────────────────────┐        │
│      │  一半繁荣，一半审视  │        │
│      │  1000x      <5%     │        │
│      │  头部估值/收入倍数   实际收入公司占比 │
│      │  资本的下一阶段...  │        │
│      └─────────────────────┘        │
│                                     │
│  脚注                                │
└─────────────────────────────────────┘
```

**Props**：

| 字段 | 类型 | 说明 |
|---|---|---|
| `title` | string | 页面标题（可选，通常省略） |
| `left` | DiptychSide | 左侧内容 |
| `right` | DiptychSide | 右侧内容 |
| `centerCard` | { title: string; comparisons: Comparison[]; conclusion: string } | 中央结论卡 |
| `footnote` | string | 脚注 |

**DiptychSide / Comparison 结构**：

```ts
interface DiptychSide {
  label: string;
  labelEn?: string;
  media?: MediaSource; // 背景图片或色块
}

interface Comparison {
  leftValue: string;
  leftLabel: string;
  rightValue: string;
  rightLabel: string;
}
```

**视觉要点**：

- 屏幕左右各占 50%，用不同背景图或色调区分两个立场。
- 中央悬浮一张对比卡，把两个极端数字并置。
- 对比卡下方给一句结论，点明转折或趋势。
- 适合“叙事 vs 现实”“繁荣 vs 审视”等冲突性主题。

## 3. 通用视觉规范

### 3.1 页面骨架

所有组件共享同一套页面骨架：

```
┌─────────────────────────────────────┐
│  PageHeader                          │
│  - title                             │
│  - subtitle                          │
├─────────────────────────────────────┤
│  PageBody                            │
│  - 主视觉区                           │
│  - 解读/辅助区                        │
├─────────────────────────────────────┤
│  PageFooter                          │
│  - footnote                          │
└─────────────────────────────────────┘
```

### 3.2 标题层级

| 层级 | 用途 | 字号建议（桌面 16:9） |
|---|---|---|
| H1 | 页面主标题 | 44~56px |
| H2 | 副标题/洞察句 | 24~32px |
| H3 | 卡片标题/数字 | 20~28px |
| Body | 描述/解释 | 14~18px |
| Caption | 脚注/来源 | 12~14px |

### 3.3 颜色使用

- **主背景**：浅色（如 `#f6f7f9` 或白色）
- **卡片背景**：白色或半透明白色
- **主文字**：深色（如 `#1a1a1a`）
- **弱化文字**：灰色（如 `#6b7280`）
- **主题色**：用于高亮、单位、标签、重点数据
- **分类色**：每个数据类别固定一种颜色，图表/列表保持一致

### 3.4 间距系统

使用 8px 基栅：

- 页面内边距：32~48px
- 组件间距：24~32px
- 卡片内边距：20~24px
- 元素间距：8~16px

### 3.5 脚注样式

- 使用等宽字体或较小字号
- 以 `/*` 或 `※` 开头
- 放在页面底部，颜色弱化
- 可包含数据来源、定义说明、趋势解释

## 4. 与 Dashi 的红线

以下可以直接学习：

- ✅ “图表 + 解读”的叙事结构
- ✅ 大数字 + 上下文 + 辅助指标卡的模式
- ✅ 颜色与分类的对应关系
- ✅ 页面信息分层（标题 → 副标题 → 主视觉 → 解读 → 脚注）
- ✅ 2~4 列主题聚焦网格

以下不能直接复制：

- ❌ Dashi 的具体配色值、字体组合、圆角大小
- ❌ 组件的精确排版比例和间距
- ❌ 中文标签文案、脚注文案
- ❌ `cover-editorial`、`bignum`、`versus` 等 slot 命名
- ❌ 图表的具体装饰样式（如渐变方向、阴影参数）
